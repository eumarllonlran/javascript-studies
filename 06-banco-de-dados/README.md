# 06 · Banco de dados

Modelagem de dados e SQL — a camada de persistência das minhas APIs.

## Assuntos

- ✅ Modelagem entidade-relacionamento (DER) no BrModelo
- ✅ Esquema lógico e dicionário de dados
- ✅ DDL: `CREATE TABLE`, chaves primárias e estrangeiras
- ✅ DML: `INSERT`, `UPDATE`, `DELETE`
- ⬜ Consultas com `SELECT`, `WHERE` e `ORDER BY`
- ⬜ `JOIN` entre tabelas
- ⬜ Funções de agregação (`COUNT`, `SUM`, `GROUP BY`)
- ⬜ PostgreSQL na prática
- ⬜ Prisma (ORM para Node.js)

## Onde apliquei

- Trabalho da faculdade: projeto de banco de dados para um sistema de hotelaria (DER, esquema, DDL e DML), em equipe
